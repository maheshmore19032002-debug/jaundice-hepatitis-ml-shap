# Jaundice and Hepatitis Prediction Using Machine Learning

## Study Overview
This project investigates the burden and predictive factors associated with self-reported jaundice or hepatitis among adults aged 45 years and older in India, using LASI Wave 1 (2017–2018) data.

## Research Outcome
Self-reported acute jaundice or hepatitis in the past two years.

## Predictors
1. Age
2. Sex
3. Caste
4. Religion
5. Living arrangements
6. MPCE quintile
7. Health insurance
8. Residence (rural/urban)

## Planned Workflow
1. Data inspection and validation
2. Data preparation
3. Exploratory data analysis
4. Train/test split and preprocessing
5. Machine learning model development
6. Evaluation under class imbalance
7. Model interpretation using SHAP
8. Tables, figures, and research reporting

## Data Privacy
The original LASI dataset is stored separately from the project outputs.
